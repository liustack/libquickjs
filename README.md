# libquickjs

Package libquickjs is a ccgo/v4 version of libquickjs.a, a library implementing
an embeddable Javascript engine.

It supports the ES2023 specification including modules, asynchronous
generators, proxies and BigInt.  It optionally supports mathematical extensions
such as big decimal floating point numbers (BigDecimal), big binary floating
point numbers (BigFloat) and operator overloading.
